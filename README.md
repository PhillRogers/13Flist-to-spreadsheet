# 13Flist-to-spreadsheet
## Create a spreadsheet from PDF downloaded from the official website.

If you have Python installed, download the Python script, right-click > Open with > Python  

Or download the self-contained, stand-alone executable program binary suitable for Windows:  
https://mft.enhance.je/www/SEC-13Flist-ToSpreadsheet.exe

If you run it without any downloaded PDFs, it will launch your browser at the download website.  
If that doesn't work, the SEC may have changed their website again, so find the right page yourself.  
Download the latest 13Flist PDF and save it into the same folder as the *.py or *.exe  

When you run it with the downloaded PDF present, it will read the PDF and extract all the data rows.  
It will then save the data rows as a CSV and an XLSX file.
